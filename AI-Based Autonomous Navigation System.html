A robot that plans, looks, and changes its mind

AI-Based Autonomous Navigation System: a virtual robot starts with a blank map, senses what is around it, plans with A*, and replans whenever the world surprises it. Watch it run below.

How it works

The robot never reads the true map. It repeats this loop every step:

  1. Sense. It looks at a square window around itself and finds which cells are blocked.
  2. Update. It overwrites its belief map with what it just saw, so obstacles that moved away are forgotten.
  3. Decide. If the current path now crosses a blocked cell, it needs a new plan.
  4. Plan. A* finds the shortest route on the belief map. Unseen cells are assumed free.
  5. Act. A separate safety check refuses any step into an occupied cell, then the robot moves one cell.

Path efficiency is the best possible length on the true map divided by the distance driven. It is below 1.0 because the robot learns the map as it goes. Collisions are zero by design: the safety check rejects unsafe moves and counts them as emergency stops.

Run it yourself

git clone https://github.com/your-username/ai-autonomous-navigation-system.git
cd ai-autonomous-navigation-system
pip install -r requirements.txt
python main.py --dynamic 4 --seed 7

The simulation on this page is a JavaScript port of the planner and belief map so it runs in your browser. The Python project adds the OpenCV perception pipeline (blur, threshold, contours) and a LiDAR-style ray scan.

Limits

It is a 2D grid with a perfect, noise-free sensor, random-walk obstacles, and no robot dynamics. Next steps are YOLO detection, sensor noise, ROS 2, and a real Raspberry Pi robot.
